# W002 — первый редактор UFD

Состояние: review. Исполнитель: чат TheBoard. Ветка: `feat/ufd-editor`.
База: `ebceb0308278646d5bd9ab5e401b9777df0fd581`.

## Цель и основания

Пользователь собирает поток из загруженных скриншотов с названиями, соединяет
экраны направленными стрелками и добавляет заметки. Основания: D1/D2 в
[описании MVP](../product/mvp-brief.md), поручение «Начинаем работу».
W001 завершена. Новых смысловых решений для этого среза нет.

Scope: загрузка PNG/JPEG/WebP, название, размещение, стрелки, заметки,
удаление объектов и их связей, навигация по полотну, понятная ошибка файла.
Non-goals: постоянное хранение, офлайн-перезапуск, архив, GitHub, совместное
редактирование. Они остаются следующими обязательствами MVP. В интерфейсе
явно сказано, что доска существует только в открытой вкладке.

Технический выбор: React + TypeScript + Vite + React Flow, статическая сборка
без сервера данных. Проверки: Playwright в Chromium. Это выбор реализации
в пределах D1/D2; внешние сервисы и платный хостинг не требуются.

## Критерии и проверки до кода

| ID | Ожидаемое поведение | Проверка |
| --- | --- | --- |

| UFD-02 | Два экрана соединяются направленной стрелкой; перемещение сохраняет связь; удаление экрана убирает стрелку | `tests/editor.spec.ts` UFD-02 |
| UFD-03 | Создание, редактирование и удаление текстовой заметки | `tests/editor.spec.ts` UFD-03 |
| UFD-04 | Испорченное изображение даёт ошибку, существующие объекты остаются; ограничение сохранения видно | `tests/editor.spec.ts` UFD-04 |

Три картинки — тестовый пример, не лимит продукта. Проверки используют
самостоятельно созданные синтетические изображения, не чужие скриншоты.

## Ход и результат

Команда `npm test -- --timeout=5000` на нём: **4 FAIL**. Vite и Chromium
запущены; UFD-01/02/04 не находят загрузку скриншотов, UFD-03 — создание
заметки. Пустая страница доступна. Это отсутствие поведения, не сбой среды.

После реализации: `npm run build` — PASS, `npm test` — **4 PASS**.
Исходные критерии и тесты не менялись. TypeScript-конфигурация дополнена
типами Node/Vite для сборки. Зависимости закреплены package-lock.json.

Браузерная проверка: загрузка трёх синтетических экранов, две стрелки,
заметка, обзор всей доски. Chromium: нет pageerror. При ширине 390px нет

и 390×844; локальные артефакты — `output/playwright/` (не коммитятся).
Это не тест всех мобильных жестов и не заявление о кроссбраузерной приёмке.
