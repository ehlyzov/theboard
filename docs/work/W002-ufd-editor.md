# W002 — первый редактор UFD

Состояние: done. Исполнитель: чат TheBoard. Ветка: `feat/ufd-editor`.
База: `ebceb0308278646d5bd9ab5e401b9777df0fd581`.

## Цель и основания

Пользователь собирает поток из загруженных скриншотов с названиями, соединяет
экраны направленными стрелками и добавляет заметки. Основания: D1/D2 в
[описании MVP](../product/mvp-brief.md), поручение «Начинаем работу».
W001 завершена. Новых смысловых решений для этого среза нет.

Scope: загрузка PNG/JPEG/WebP, название, размещение, стрелки, заметки,
удаление объектов и их связей, навигация по полотну, понятная ошибка файла.
Non-goals: постоянное хранение, офлайн-перезапуск, архив, GitHub, совместное
редактирование. Они остаются следующими обязательствами MVP. В интерфейсе
явно сказано, что доска существует только в открытой вкладке.

Технический выбор: React + TypeScript + Vite + React Flow, статическая сборка
без сервера данных. Проверки: Playwright в Chromium. Это выбор реализации
в пределах D1/D2; внешние сервисы и платный хостинг не требуются.

## CI и интеграция

[PR #1](https://github.com/ehlyzov/theboard/pull/1).
[Первый CI кандидата](https://github.com/ehlyzov/theboard/actions/runs/42501134314)
успешен: npm ci, сборка, установка Chromium, четыре теста, загрузка отчёта.
Последний SHA PR проходит отдельный обязательный `editor-checks` перед merge.
Следующий за review коммит содержит только отчёт, статус и ignore локальных
браузерных логов; его SHA не выдаётся за SHA проверенного продукта.

Защита main настроена и прочитана через GitHub API: обязательный
`editor-checks`, актуальность относительно базы (strict), PR, разрешённые
обсуждения, применение к администратору; force push и удаление запрещены.
Обязательных человеческих code-review approvals нет; независимый агентный
отчёт и функциональная приёмка владельца остаются разными фактами.
Серверный запрет обхода не испытывался отдельной вредоносной попыткой.
