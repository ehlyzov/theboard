# W003 — локальные доски и переносимый архив

Состояние: active. Исполнитель: чат TheBoard.
Основание: поручение пользователя через PlanItForMe подготовить отдельную
локальную UFD-доску, при необходимости доработать импорт, подписи переходов
и сохранение; не публиковать материалы и не сбрасывать чужие доски.

Критерии: ARCH-01 импорт ZIP со скриншотами, подписями и заметками создаёт
новую доску; ARCH-02 reload сохраняет содержимое, изменение заметки и подпись;
ARCH-03 экспорт и импорт в чистом профиле восстанавливают данные;
ARCH-04 неправильный ZIP не изменяет текущую доску, другая доска сохраняется.
Тесты до реализации: tests/archives.spec.ts. Изображения только синтетические.
Формат v1: ZIP board.json {version:1,title,nodes,edges}, image — путь assets/*.
Хранилище IndexedDB по board ID; импорт всегда выдаёт новый ID.
GitHub-синхронизация и offline shell не входят. Human acceptance: pending.
